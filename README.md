CB Creaciones 3D

Descripción del proyecto

CB Creaciones 3D es una página web desarrollada para un emprendimiento de impresiones 3D personalizadas, me inspire en hacer una pagina web porque planeo tener un emprendimiento de impresiones 3D con mi novia

El sitio permite conoce productos, visualizar imágenes de las creaciones y realizar consultas.

Tecnologías utilizadas

HTML5: estructura de las páginas.

CSS3: diseño, colores y distribución de los productos mediante Flexbox.

JavaScript: validación del formulario y funcionamiento del carrusel.

Git y GitHub: control de versiones y almacenamiento del proyecto.

GitHub Pages: publicación de la página web.

Funcionalidades

Menú de navegación entre Inicio, Productos y Contacto.

Catálogo de productos con imágenes y descripciones.

Carrusel de imágenes con botones para avanzar y retroceder.

Formulario de contacto con validaciones mediante JavaScript.

Visualización de un resumen de la consulta.

Estructura del proyecto

index.html: página principal.

productos.html: catálogo de productos.

contacto.html: formulario de contacto.

css/estilos.css: estilos de la página.

js/carrusel.js: funcionamiento del carrusel.

js/contacto.js: validaciones y procesamiento del formulario.

img/: imágenes de los productos.
